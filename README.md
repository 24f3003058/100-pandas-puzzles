# 100 Pandas Puzzles

A worked-through notebook of the well-known "100 pandas puzzles" — progressively harder exercises covering the pandas library, from DataFrame basics to advanced indexing, grouping, and time series operations.

## Contents

`Challenge100.ipynb` — solutions and notes covering:
- DataFrame creation and inspection (`pd.DataFrame`, `.info()`, `show_versions()`)
- Indexing, selection, and filtering
- Grouping and aggregation
- Merging, joining, and reshaping
- Time series basics
- Cleaning and handling missing data

## Running

```bash
pip install pandas jupyter
jupyter notebook Challenge100.ipynb
```

## Why

Built as hands-on practice to build fluency with pandas' core API — the kind of muscle memory that's directly useful for the data preprocessing and analysis work in the IIT Madras BS Data Science coursework.
